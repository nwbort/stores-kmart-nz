# Kmart store locations (New Zealand)

Regularly updated store list for Kmart New Zealand.

- `nz-store-locations.json` - raw store list from the kmart.co.nz store locator API
- `stores.json` - store details extracted from each store's page on kmart.co.nz

Unlike the [Australian scraper](https://github.com/nwbort/stores-kmart), the store list
does not come from the sitemap: kmart.co.nz's `storelocation-sitemap.xml` lists
Australian stores, not NZ ones.
